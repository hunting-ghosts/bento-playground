# Join in

Try a pattern, find an awkward workflow, make a sound, fix a bug. All useful.
Open an issue with what you were trying to do and what happened; for code,
small focused changes are easiest to review.

Please keep firmware files, personal projects, samples and account details
out of issues and commits. Share the offline patcher, not the install ZIP it
makes. Back up your Bento before testing anything.

The [developer guide](docs/DEVELOPER_GUIDE.md) is a starting point if you'd
like to work on the code. Keep the existing licenses and be clear about
what was checked in software versus on a real device.
