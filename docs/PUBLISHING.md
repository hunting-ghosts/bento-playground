# Sharing Playground

Share source, not firmware. Every build contains manufacturer code, so a
generated `bento1.bin`, restore files or install packages must not be
uploaded, attached to issues or passed around. Each person builds from their
own original files.

Source snapshots contain current source and guides, not development archives
or old tester packages. Build source is copied unchanged; user-facing docs
live separately. `SOURCE_MANIFEST.json` records the source hashes.

Before sharing another snapshot, reproduce the image from the exported source,
preserve the licenses, and review the outgoing files for firmware, personal
data and private notes. Software checks and hardware results need to stay
separate.
