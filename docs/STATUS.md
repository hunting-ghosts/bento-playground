# Status

Bento Playground is still in development. I’m not looking for testers right now, so there’s no download at the moment, just the source.

The source here is the build I’m currently running on my own Bento. It shows up in Settings as **P168 exp8b**, and building it unchanged with that label gives this application SHA-256:

```text
6ec8d50fb4dd43241c50a15d38a6832bdcf54f3fb45b423f85a6b0f361de7bff
```

Every change runs through the test suites in an emulator before it goes anywhere near a device (for this build: 80 of 80 suites, on 1.6.8 and 1.6.1). That doesn’t prove much on real hardware, though. Only the Bento itself does.
